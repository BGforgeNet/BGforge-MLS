# Corpus scripts whose decompiled source REPRINTS to different bytes than it was compiled from.
#
# Not defects. A string constant's position in the string table follows the order the source mentions
# it, and no spelling of an expression says where its literals go - so the printer shifts bytes without
# changing what the script does. The resave gate, which seeds the emitter with the original string
# order, demands every one of these back byte for byte and admits no exclusions.
#
# Pinned by path rather than counted. The count this replaced (a floor of 1289 against 1544 compiled)
# had exactly one script of slack, so it was already this set with the names left off - and a name list
# decomposes across the sweep's shards, where a corpus-wide count cannot. Paths, not stems: two corpus
# directories each hold a `waypnt.ssl`.
#
# Regenerate by reading the sweep's failure report, which names what entered and left the set. An entry
# LEAVING is a fix - drop the line. An entry ARRIVING is a printer or front-end regression until shown
# otherwise; do not add one to get to green.
